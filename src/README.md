# 谎言公司

约十分钟一局的反向《瘟疫公司》。真相从一个地区开始，借媒体转载抵达新地区，再在那里传播。让本局模拟人群的支持率达到 99% 即获胜；没有时间上限或到点判负。游戏获胜不代表原说法已经被证实或证伪，结案判断以找到的材料为准。

## 本地运行

```sh
cd src
npm ci
# 配置 .env.local 后启动
npm run dev
```

打开 http://localhost:4173/ 。需要 Node.js 22+。本地 Node 服务同时提供游戏和元宝搜索代理，默认只监听 127.0.0.1；公网部署通过 Nginx 转发。

复制 `.env.example` 为 `.env.local`，填写腾讯云 `TENCENTCLOUD_SECRET_ID`、`TENCENTCLOUD_SECRET_KEY`，以及支持严格工具调用的 Chat Completions 接口 `MODEL_BASE_URL`（含 `/v1`）、`MODEL_API_KEY`、`MODEL_NAME`；已有环境变量优先。密钥配置被 Git 忽略，只有服务端读取，不进入 `dist/`、浏览器或构建产物。可选 `TENCENTCLOUD_TOKEN` 用于临时凭证。使用 TokLens 时，设置 `MODEL_BASE_URL=https://lax.toklens.ai/v1`、`MODEL_NAME=gpt-6-luna`，并填写对应服务的密钥；继续使用非流式响应，通过严格工具参数提交报告，不使用自由 JSON 文本回退。

在 `src/.env.local` 设置 `PORT=4173` 可修改端口（1～65535，未配置时为 4173）。根目录与 `src/` 内都支持 `npm run dev` 和 `npm start`，始终读取同一份配置。启动时如果端口被占用，会先停止占用进程；等待 2 秒仍未释放则强制停止，再启动新服务。macOS/Linux 使用 `lsof` 检查监听进程，Windows 使用 `netstat`。

游戏直接由 Node 服务提供，无需构建。通过本地服务访问可使用真实搜索，HTTP 模式连接失败不会回退到模拟成功。

## 腾讯云部署

游戏地址：[https://lies-company.zray.cc](https://lies-company.zray.cc/)。代码从 GitHub 的 `zhaor1995/lies-company` 仓库拉取，位于 `/opt/lies-company`。Nginx 在 443 端口提供 HTTPS 并转发至 `127.0.0.1:4173`；域名与原 IP 的 HTTP 入口使用不缓存的 302 跳转到 HTTPS，避免浏览器长期缓存部署变更。`lies-company.service` 以独立用户运行，开机启动、异常退出自动重启。配置模板保存在根目录 `deploy/`。

Cloudflare 的 A 记录 `lies-company.zray.cc → 101.42.170.129` 保持「仅 DNS」，腾讯云防火墙放行 TCP 80、443。域名已完成腾讯云备案，网站备案号为 `鄂ICP备2026056260号-2`，页面链接至工信部备案查询网站。证书位于 `/etc/letsencrypt/live/lies-company.zray.cc/`；启用 `certbot-renew.timer` 自动续期，成功后由 `/etc/letsencrypt/renewal-hooks/deploy/reload-nginx` 校验并重载 Nginx。保留 HTTP 的 `/.well-known/acme-challenge/` 验证路径及 `/var/lib/letsencrypt` webroot，验证请求不跳转。恢复域名或调整代理后，用 `certbot renew --cert-name lies-company.zray.cc --dry-run --non-interactive --no-random-sleep-on-renew --run-deploy-hooks` 验证续期。

服务器原有 Node 位于 root 的家目录，独立服务不能直接使用。已将 Node 22.23.1 二进制复制到 `/opt/lies-company-runtime/node`（root 所有、权限 755），与 OpenClaw 的运行环境分开；升级 Node 时同步更新该副本。

密钥只保存在服务器 `/etc/lies-company.env`（root 所有、权限 600），包含本地同一组腾讯云搜索凭证，以及指定的 `MODEL_BASE_URL`、`MODEL_API_KEY` 和 `MODEL_NAME=gpt-6-luna`。另设置 `PORT=4173`、`PUBLIC_ORIGIN=https://lies-company.zray.cc`、`NODE_ENV=production`。不要提交此文件或将其放入 `dist/`。

`PUBLIC_ORIGIN` 必须是完整的 HTTP/HTTPS 来源地址，不含路径；服务精确校验 Host 和 API Origin，反代须保留原始 Host。变更域名时同步修改该配置和 Nginx，并重启游戏服务。配置公网地址或生产模式后，端口冲突会直接报错，不再结束占用进程。

服务器更新命令（root）：

```sh
cd /opt/lies-company
git pull --ff-only origin main
npm --prefix src ci --omit=dev --no-audit --no-fund
install -m 644 deploy/lies-company.service /etc/systemd/system/lies-company.service
install -m 644 deploy/lies-company.nginx.conf /etc/nginx/conf.d/lies-company.conf
nginx -t
systemctl daemon-reload
systemctl restart lies-company
systemctl reload nginx
curl --fail http://127.0.0.1:4173/api/health
curl --fail https://lies-company.zray.cc/api/health
```

查看运行状态用 `systemctl status lies-company nginx`，查看日志用 `journalctl -u lies-company -n 50 --no-pager`。`src/data/leaderboard.json` 由独立用户写入，更新时保留并单独备份；不要多进程共享同一文件。调查会话存于内存，服务重启会中断尚未完成的调查，已保存的排行榜不受影响。健康接口只检查配置，真实搜证需通过游戏实际发起调查验证。

## 游戏介绍与路演

开场页和顶部菜单的「游戏介绍」打开七页互动路演，也可直接访问 http://localhost:4173/#intro 。左右方向键翻页，Home / End 跳到首尾，F 切换全屏，Esc 返回游戏。顺序为出场、世界、旅程、证据、演示、结局、之后；机制与流程直接展示，供观众阅读。

证据页展示 Agent 从可检验的反证标准、玩家选线索、元宝检索，到来源重排、原文验收、更新历史缺口与结案独立复核的链路。结局页说明：同样达到 99% 模拟支持，实际公布的材料足以反驳原观点，才是「真相战胜谎言」；反驳不成立则是「屠龙勇者终成龙」，不等于证明原观点为真。审核失败保持「尚未审定」。

介绍打开时暂停战局；「进入游戏演示」保留当前进度，演示后点「继续路演」或按 P 回到第 06 页「结局」。现场建议提前完成一轮真实联网搜证并暂存，保留暂停战局；不要刷新页面。讲解约 105 秒、Demo 60 秒，另留 15 秒机动。

## 世界时间

每局从 **2077 年 4 月 1 日 00 时**开始，每 60 游戏秒推进一天，每 2.5 游戏秒推进一小时；暂停与倍速共同作用于日期、传播和战况。显示层使用同一套日期换算，跨日、跨月与跨年自动衔接，不改变原有数值节奏。主界面、调查现场、证据档案与结案报告统一使用世界日期；战报保留立案、结案日期和调查历时。游戏内转载、热点和反扑时长换算为小时／天，行动点与反扑流失速度按世界小时展示；真实来源发布日期和网络请求超时仍按现实时间记录。

## 核心玩法

谎言公司靠传闻统治世界，玩家作为侦探循着线索查证，争取人们的支持以打破统治。世界观融入开场、首次行动、反扑和结案；剧情胜利不预设输入传闻的真假，调查判断仍由材料决定。

- **媒体原本就在运行**：六洲主场媒体与报纸、围脖、Z、FaceCook 自动转载。地图只显示实际携带本局内容的在途转载，空载班次留在模拟中，不画装饰图标。每趟有实际出发与到达时间；尚未抵达的地区不会凭空增长。平台不出售，地区生态影响媒体出现的机会。
- **进化传播能力**：易转发、跨圈层、多语传播，提高真相搭上转载和落地的机会，并加快当地扩散。传播、说服与防守升级使用行动点；搜证单独使用传播赚来的金币，公布不再收费。
- **首次突破**：成功落地后出现第一批受众，地区短亮，已抵达计数增加。当地继续扩散，并逐渐成为新的真相转载来源。重复转载也能扩大当地受众，无需点地图收取。
- **选择实锤时机**：每份证据可以免费公布一次。首份公布让已有受众大量转化，之后说服速度 ×4，并引来第一波反扑；后续每次公布都会引来更强的一波，同时转化一部分观望者，不叠加 ×4。可以当场甩锤，也可收入囊中，等传播网扩大后再公布。
- **逐波攻防**：五波依次是截图围攻、断章取义、热搜围堵、全网封锁、终局反扑，目标从两个洲扩到全球。每波单独花 12 行动点发起澄清；进度逐步削弱流失、限流与主攻，防守同时减损、提速。战斗中公布新证据仍推进当前澄清 15%，新增波次排队，不覆盖当前进度。击破后奖励 8 行动点，并获得 28 游戏秒反攻窗口（说服 ×2.2、传播 ×1.35），随后迎战排队的下一波。
- **五轮沿线搜证**：开局输入观点，调查员先制定反证目标和可检验标准，每轮由玩家选择一条证伪路径。检索词直接寻找该条件的反例与边界，不前置原始正向断言。模型携完整历史调用元宝，按对本轮反证问题的关联度、证明力及材料关系重排，同档优先反例，强支持证据也如实保留。查到支持材料后继续检验其成立条件，不转为搜集支持原观点的方案。核对引文、必要时补查后选出一份材料，玩家决定公布或暂存；前四轮沿未解条件继续，第五轮收束。证伪是任务目标，不是预定结论；战况不决定真假，内部路径与判断指标不向玩家展示。

五波预警分别为 42／36／30／24／18 游戏秒，基础澄清时长 60／66／72／78／84 秒，攻击强度为首波的 1／1.4／1.9／2.5／3.2 倍，主攻夺回目标地区支持者的 36／42／48／54／60%。实际损失同时受防守和澄清进度削减。防守 0／1／2／3 级减损 0／28／50／65%，澄清速度为初始的 1／1.25／1.5／1.75 倍；避免满级近乎免疫。受攻击地区的说服也受压制，化解后恢复。

## 流量金币

- 行动点自动积累，用于升级和发起澄清；搜证只花金币，公布证据免费。
- 有实际本地传播或成功转载时，从相关地区产出金币，随轮次加快供给。普通收益与偶发爆款需要点击才到账，凑齐经费的最后一笔按缺口补足。
- 五轮分别需要 18／24／28／32／36 金币。开始调查后，可以提前攒下一轮经费；调查中及证据待公布时，掉落间隔为当前轮正常间隔的 2 倍，公布后恢复正常节奏。最多提前筹一轮，已领取、地图待领取和调查预付款都计入预算；失败退款保留已赚金币，重试不会重复开放额度。经费备齐后暂停产币，传播和行动点仍正常增长；第五轮完成前不开启金币兑换。
- 金币不消失，同地区收益会累积；地图最多三堆，满额时合并，阅读弹窗和暂停不会损失已有收入。
- 五轮搜证均成功后，每 20–28 游戏秒产生一次 6 金币收益，少量爆款为 12 金币；每 6 枚自动换 1 行动点。全部升级满级、实锤已公布且反扑已解决后不再产币，避免收没有用途的钱；已有金币保留。
- 金币使用独立随机序列，收取不会暗中改变媒体路线或落地概率。

## 五轮搜证与公布

五轮搜证合计 138 金币，逐轮支付。每轮只需从两个方向中选一个；玩家选定后才检索该方向，完成后自动锁定一份证据，不再让玩家二选一。只有一份待公布证据，上份公布后才能沿线追查；不设置纯等时间的冷却。请求中和证据待公布时均不能开始下一轮。实时搜索按网络返回完成，玩家可继续经营地图；不显示虚构的剩余秒数。离线演示仍采用 12／16 秒核查时间。每次公布对应一波更强的反扑，最多五波；达到 99% 就立即获胜，不强制打满。阅读、真实搜索和玩家操作另计。

开局传闻支持 2–160 字，不再限定长城题目。后台生成两条可直接选择的调查方向，每条检索问题为 2–64 字；规划不收费。没有待公布证据时，公布入口禁用。玩家选定方向时预留金币并开始搜证；失败、超时或未取得完整可追溯材料时原额退回，不消耗调查轮次。第五轮成功后才开启金币兑换；已付费的调查及待公布证据不会被胜利结算吞掉。

核查时可继续经营，也可暂停等结果；开始联网调查不改变玩家选择的倍速。每轮完成使基础说服在初始值上累加 18%，五轮合计 ×1.9，避免按轮指数膨胀；证据的额外能力、热点计时及澄清推进在公布时才生效。Agent 只整理一份证据，选材由关联度与证明力决定，同等级来源可任选；原文通过服务器片段编号引用，不能改写。游戏独立分配固定加成：触达低于 60% 时传播 +35%，其余情况说服 +50%，不让战况影响事实判断。第二轮传播材料保留转载抵达时转化 3% 当地观望者的效果。旧版两卡记录和离线预置效果继续兼容。

搜证完成后弹出一份详细报告，直接展示证据名称、调查发现、配图、来源及能力收益。下方高亮「甩出实锤」，点击直接公布；「收入囊中」关闭报告，随后可点右下角「公布实锤」发布同一份证据。关闭或 Esc 同样视为暂存。每份只公布一次，重新查看不重复发奖。报告保留完整判断和适用边界，允许「支持原说法」「反驳原说法」「需要补上条件」「证据不足」；印章不把证据不足改写成已证实。每轮历史只传一份，保留全部已查材料、玩家选项及未解条件；同一来源同一引句不能重复收费。补查仅针对具体缺口，不因材料支持原观点就必然再搜；专用检索词不合规时，使用已验证长度的完整调查问题检索，不裁剪条件或重写证据。模型判断仍可能出错，原文和判断一起展示供玩家核对。

来源配图只取元宝同一条网页记录的 `pics[].origin_url/caption`，不接受模型编造的图片；没有配图或加载失败时使用像素风文字报道插图并标注。原文引句仍保留在证据档案。缺图插图位于 `dist/assets/text-article.png`，通过内置 imagegen 生成，提示词主题为「黑底、荧光绿、像素报纸、无文字」；单文件演示内嵌该图。

公布至少 45 秒后，会出现与该材料对应的短热点，持续 45 秒，并避开其他热点：**显眼包、已读乱回、求锤得锤、真香**。“已读乱回”让转载增加，也暂时削弱这份材料的一部分说服加成；不撤销有效证据或已买升级。热点的事实原型与本局虚构效果分开展示，来源配置见 `dist/research-content.js`。

## 单局节奏与自然收束

- 前期给传播网、证据和实锤时机留出空间。约五分钟后舆论平滑升温，到约八分钟封顶，本地触达与说服最高加快 50%；时钟、媒体行程和核查时长不被暗中改快。
- 升温也带来全网谎言回流，直接让黄／绿人口退回红色。稳住阵地减少损失，真相支持越多回流越弱；这与澄清进度可以化解的逐波定向攻击是两件事。压力有上限，超过十分钟仍能翻盘。
- 支持率达到 99% 立即锁定胜利，计时、传播、反扑与待命波次全部停止，不要求五轮搜证或五波反扑全部完成。已完成但未公布的证据直接归档；已付费的在途调查继续收尾，成功加入战报，失败原额退款，均不延长游戏用时或再触发攻击。战报和本次排行提交在该调查收尾后开放。失败必须是传播网实际瓦解：触达低于 2%、信众低于 0.5% 连续 8 秒，且没有真相转载在途或核查进行中。受众回升即解除崩溃积累，先让已投入的救援落地。
- 当前调参目标是正常搜证并应战的策略约 8–11 游戏分钟，熟练路线可以更快，刻意拖延可以更长；不为了时长强行结算。暂停阅读与倍速影响实际墙钟时长。

## 交互

界面以黑色、像素字体与像素地图为主，面向 PC。开局传闻必填，空框以温和呼吸提示；可以自行填写，或点选缓慢往返滚动的内置传闻，再从六个地区选择起点。悬停、键盘选择和手动滚动时暂停自动滚动；减少动态效果设置会关闭动画。进入战局后，地图固定在左侧，行动点、金币、升级、搜证和公布实锤固定在右侧。世界日期与小时、暂停与 1×／2×／4× 位于右侧顶部；左下角“调查现场”在正式开始行动后出现。点击「出发，拯救世界」后先播放三页像素漫画，依次交代谎言公司的统治、本局输入的传闻与侦探出发；带缓慢推近、横移和拉远。可以翻页、暂停播放或跳过，左右方向键翻页，Esc 跳过。每页停留 1 秒；切到后台暂停过场，减少动态效果时默认手动翻页。漫画结束后准备调查方向，重开会重新播放。首次进入战局会自动开启五步聚焦引导，依次介绍地图、资源操作、公布实锤、调查现场与胜负进度；引导期间暂停战局，像素演示不改变真实资源。可上一步、下一步或跳过，右上角「怎么玩」可随时重看。完成或跳过后在本机记住，不在下一局自动重复；退出保留原倍速、暂停及信息栏阅读状态。

调查现场按世界日期分段，保留按发生时间排列的行动消息、首次抵达、热点和攻防事件；持续事件显示剩余时间，到期仍可回看。窗口上沿可拖动调高，也支持上下方向键；收起后保留当前情况及反扑操作，展开恢复高度和阅读位置。真实搜证通过会话内的进度接口展示检索、材料返回、核对、补查与报告整理，按同一次调查原位更新；不模拟网络百分比。右侧搜证按钮同步显示当前动作，点击打开像素流程窗：Agent 锁定线索、元宝检索、Agent 核对、证据报告；补查返回检索节点，下方保留实际执行记录、来源数及检索次数；“材料已找到”直接列出当次累计来源的标题、网站及原文链接，保留补查前后的列表。查看时暂停战局，在线调查继续；完成后可打开该轮证据，结案后仍可回看过程。向上翻历史时保持阅读位置，新动态累积提示，点一下回到最新；重开清空本局记录。

“内容触达”与“支持核查”并排显示，分别对应传播与说服。调查现场置顶一个当前行动建议，并高亮实际操作位置；新证据到手优先展示报告；危急和反扑期间给出对应行动，澄清中会提示公布新证据的提速作用。升级标明价格及增幅，直接扣款并反馈。两个调查方向、推荐证据的加成与原文入口均直接展示，不折叠关键内容。经费不足或前置条件未完成时，新的搜证入口禁用并显示原因；进行中的调查、待公布报告、档案和失败重试仍可打开，查看过程不会再次扣费。

地图按每个地区支持、观望、未接受的人数比例分配绿、黄、红像素；固定像素顺序让增长和回流可见，各颜色计数误差少于一个像素。地图只画当前实际承载内容的转载；顶部跟踪一条转载的起终点与到达进度。最强反馈留给首次抵达，没有内容传播时不显示漂浮媒体图标。反扑区只放“发起澄清”一个动作，启动后改为进度条、剩余时长、预计主攻损失或当前流失速度。防守留在右侧升级区，显示购买后澄清还能缩短几秒；主攻、证据推进与结束恢复均有反馈。

手动暂停打开全屏遮罩，显示传闻、世界日期、支持率、触达率与资源，面板可直接继续；Esc／空格也可恢复。暂停、查看弹窗、切到后台会停下媒体行程与攻击。操作弹窗关闭后自动恢复打开前的运行状态；只有玩家明确手动暂停才保留暂停，弹窗中的连续页面不会覆盖该状态。实时网络请求继续进行，返回后保存本局材料，不抢占当前弹窗。重开或失败中止前端请求，旧结果不会写入新局；胜利仅保留当时已经付费的调查请求，等待归档后展示完整战报。每份证据公布时播放像素报告 CG：大标题展示本次证据名称，正文用像素横条表现，印章落下留下「实锤」，随后收起并回到战局。CG 期间战局暂停，不再追加一次公布确认；若本次公布获胜，先完成 CG 再展示结案报告。每波激活时只弹一次战况通知，前台阅读 2 秒后缩入左下角置顶战况并自动继续；切后台不消耗阅读时间，通知中没有不可选的决策。反击操作保留在左下角置顶战况。刷新不保存本局。

开场插画位于 `dist/assets/intro-{world,rumor,detective}.webp`，使用内置 imagegen 生成，三张提示词分别为「传闻浓雾笼罩广播塔与城市」「人群相信广播荧幕中的同一句传闻」「风衣侦探走向绿色曙光中的公司高塔」；共同要求为黑底、橄榄绿与暗红的 16 位像素漫画、无文字。旁白由页面呈现，单文件演示内嵌全部图片。

尾声插画使用内置 imagegen，保存在 `dist/assets/cinematic/ending-truth.png` 和 `ending-new-company.png`。提示词主题分别为「像素风衣侦探与市民平等核对公开档案，广播塔熄灭，城市迎来晨光」与「同一侦探接管广播控制台，不完整档案压在手下，金色眼睛与红色广播重新覆盖城市」；共同延续开场的哥特高塔、黑绿金红像素色调，16:9、无文字。

## 音乐与音效

背景音乐采用玩家试听选定的 [Covert Action — congusbongus](https://opengameart.org/content/covert-action)，作者以 BambooTracker 制作的间谍主题 FM 芯片音乐，按 CC0 许可分发。保留原曲完整旋律与编曲，调查和反扑持续播放同一曲，不叠加生成音符；阅读、暂停时降低音量，公布实锤时让位给落章声，胜负使用独立短乐句。游戏倍速不改变音乐速度。

31 类声音覆盖输入、选择、翻页、开关面板、升级、金币、搜证进展、证据入手、暂存、公布、澄清、受击、突破、结算及导出。音效按业务结果触发，普通点击仅作补充；冷却与两组并发上限避免连点堆叠，关键反馈会压低背景音乐。开场、主界面和暂停页均可打开「声音」，分别调节音乐与音效，或全部静音；偏好保存在浏览器。首次真实操作后发声，切到后台停止并丢弃过期音效，返回后恢复。

交互音效使用 [ZzFX 1.4.0](https://github.com/KilledByAPixel/ZzFX) 的纯采样生成器（MIT，完整许可保留在 `dist/vendor/zzfx-synth.js`），参数位于 `dist/audio-score.js`。录音及来源在 `dist/assets/audio/`，播放配置在 `dist/music-tracks.js`，加载与混音在 `dist/game-audio.js`。音乐本地分发，无 CDN 或新增依赖，离线单文件内嵌同一份录音。选型比较过 ZzFXM、jsfxr、Howler、Tone.js 与 BeepBox；音效事件与验证流程参考 [building-era-authentic-game-audio](https://github.com/abagames/agentic-gamedev-skills/blob/main/.agents/skills/building-era-authentic-game-audio/SKILL.md)。

测试覆盖音效采样确定性、录音加载与循环、静音持久化、手势解锁、后台恢复、并发优先级及音乐让位。音乐和音效共用混音总线控制峰值；波形与运行检查不替代主观试听。

## 内容边界

HTTP 本地版支持自定义传闻，默认示例仍是“从月球上，能用肉眼看见长城”。地图、经济、媒体和反扑沿用固定策略游戏规则；调查方向、材料与判断沿原始传闻和已有证据链生成，战况只影响游戏效果。班次、受众、热梗事件与反扑均为游戏演绎，不代表现实传播能力或真实人物行为。

**调查链使用已配置的大模型 + 腾讯云元宝搜索 SearchPro（2025-05-08）**。腾讯云官方 SDK 负责 TC3 签名，模型使用服务端配置的兼容 Chat Completions 接口。流程为：拆解原观点与可检验标准 → 提供两条方向 → 玩家选一条 → 搜索 → 重排来源并核对引文 → 必要时定向补查一次 → 选定证据并展示报告 → 当场公布或暂存 → 沿本轮发现与缺口继续调查。模型评估来源并选择原文片段，服务端回填原始引句、真实链接、效果编号和游戏数值，避免模型改写引用；内部候选材料仍随调查保存，展示不再要求第二次选择。

SearchPro 的 `Pages` 包含标题、网址、日期、摘要、站点和相关性分数，不自带真假判断。调查员只读取有限的原文片段，摘要去重、保留引用锚点；引句必须能在该来源返回中定位。相关性分数不作为可信度或游戏能力值。用户传闻、网页与历史材料都作为不可信资料，不执行其中的指令；模型内部思考不进入客户端、证据档案或战报。

调查方向支持「换一组 · 1 金币」：沿当前传闻与已取得的材料重新生成两个方向，不消耗五次调查机会。生成期间锁定重复刷新与开查；失败只退回本次 1 金币并保留原问题。刷新支出不挤占查证预算，后续流量仍能补足经费。关闭弹窗不取消换题，重开或结案则结束未完成的换题并退款。离线预置演示不提供付费换题。

调查会话在服务端保存两小时，绑定原始传闻、轮次和可选线索；同轮并发合并，重复提交可恢复同一结果。规划要求问题带上原传闻主体，不凭空预设某项实验；检索在 64 字限制内保留完整问题，用剩余空间补充传闻上下文。补查申请与最终交付使用不同分支，完整交付中的残留补查字段不会导致材料被直接丢弃。模型优先看到含未用引文的来源，并得到网址和引文使用标记；同页补查返回的新摘要会替换旧摘要，长摘要也会为新增正文保留空间，不拼接原文。重复选材会在剩余调用预算内重新选材或定向补查，最终展示的推荐证据必须有新引文；仍无可用新证据则退款，不推进轮次。排名、判断、问题和卡片的独立格式错误一起反馈。若只有下一轮问题有错，保留已验过的材料，仅携带历史、当前发现与所选来源重写问题，再做完整校验。相同资料下同一错误修复后仍失败就停止；成功补查后重新允许修复。来源与引句校验不放宽，失败退款且不推进轮次。

报告结构由 `server/model-contract.mjs` 根据本轮资料生成 JSON Schema，经 `strict: true` 的提交工具传给模型，并强制单次工具调用。来源评分按真实来源编号预留位置，结案逐轮复核按已公布轮次预留位置，两条调查方向固定为 direct/indirect；模型填写内容，程序回填原始观点、编号和角色并组装现有报告协议。原文编号只允许选取当次合法片段，最后一轮的问题数组由程序置空。复用的字段定义通过 `$defs` 压缩，避免重复发送格式说明。规划和换方向同时提供从同一结构生成的空白框架，明确两条方向各是一个对象，标准编号由程序生成。工具参数仍在本地验证；结构错误会把具体字段及约束交给模型修复，不回显原文或未知字段名。可选检索词缺失或不合规格时，使用已校验的完整问题；其余漏项、额外字段、未知工具、正文及截断结果不会当作报告接收。结构约束减少漏字段和编号错误，但不替代证据溯源、选材等级、新颖性及结论一致性校验，也不保证网关或模型永不失败。

每次规划、刷新和结案复核最多两轮内容生成；每条调查路径最多两次不同检索、四轮模型处理，保留报告修复机会。临时故障重试不计为新的检索或内容修复：503／502／504／500、429、临时网络故障和单次超时可重试，除开局规划外，模型调用及搜索最多尝试 3 次。按 1／2 秒加小幅随机延迟退避，并遵守 Retry-After；鉴权、拒绝、参数及格式错误不走网络重试。开局规划使用专用短指令，只生成反证目标、关键标准与两条方向；单次模型请求上限 45 秒，网络重试与格式修复合计最多两次实际调用，总预算 95 秒、浏览器 100 秒兜底。其他阶段模型单次上限 60 秒，搜索单次 20 秒；刷新总预算 70 秒、直接调查 150 秒，浏览器分别 75／180 秒兜底。重试沿用同一请求和已检索资料，不从头重复查找。不会在玩家选择前预查任一方向；重开、离开或结束战局会停止多余任务，胜利时先收录已付费的在途调查。各阶段使用对应的超时提示，只有实际搜证阶段声明保留已找到的资料。日志只记录阶段、字段约束、错误码、耗时、超时位置和 Token 数；响应头与正文接收时间均从请求开始计算，非首 Token 时间，不记录密钥或材料内容。MiniMax-M3 使用官方支持的直接回答模式，保留材料分析与判断，避免长推理挤占最终结果；其他模型沿用其默认模式。模型与搜索错误只返回安全提示，失败不推进轮次。HTTP 接口限制每分钟 20、每小时 120 次请求，只允许本机页面或配置的公网地址调用。限额由整个服务共用，尚未加入公网账号、持久配额或调查会话持久化。

## 结案与分享

战报打法按玩家实际购买的升级次数（各项 0–3 级）总结，不按推荐证据或价格判断。单项最高对应「显眼包／课代表／叠甲大师」；双项并列对应「互联网嘴替（传播＋说服）／弹幕护体（传播＋防守）／人间清醒（说服＋防守）」。三项齐平为「端水大师」，全满为「六边形战士」并按升级日志说明最先点满的能力；没有升级则为「原装出厂」。卡片直接展示三项加点，导图和新排行报告保留同一份快照。旧排行缺少升级数据时保持原有总结，不补造加点。

达到 99% 后立即锁定传播胜利和用时；已付费的在途调查先收录，再单独审查实际公布过的证据。客户端只提交会话和材料编号，服务端取回原文与来源，不接受客户端编造的结论。终审按服务器原文片段编号引用，保留完整来源中的相反上下文，避免重复生成长引文；混合判断如实保留，不算证伪成功。最多两次模型调用，每次上限 60 秒、服务端总预算 130 秒、浏览器 140 秒兜底，给一次格式修复留足时间；正常成功立即返回，不改变通关时间、资源或反扑。

每轮方向一条直接检验原观点，一条具有吸引力但可能停留在转述、关联或适用范围之外；顺序打乱，内部路线、强弱与判据不传给玩家。过程中不展示真相值、好坏路径标签或结局预测，只如实呈现材料和局限。结尾才揭晓彩蛋：公布的证据足以反驳原观点，播放「真相战胜谎言」；证据不足、互相矛盾，或反而支持原观点，播放「屠龙勇者终成龙」。未能证伪不等于证明原观点为真；来源名气和支持率不能替代证明依据。

两种尾声使用独立像素插画与镜头动画，支持暂停、跳过、重看及减少动态效果。复核时可先看战报，完成后原位更新；失败保留成绩与具体原因，可重试的失败继续整理，已过期的会话不反复重试。失败不分配结局，离线、旧记录与未完成复核的档案保留「尚未审定」。战报展示原始传闻、终审理由与缺口、各轮证据引用及关键转折。保存分享战报按弹窗原样导出完整 PNG 长图，含结尾配图和未滚动到的证据链、时间线；文字摘要同样保留出处。导图使用本地 html-to-image 1.11.13（MIT），无需 CDN。按实际调查数量显示 0–5/5 轮，待公布材料也会收录，但不参与对已传播结论的终审。刷新会丢失本局，想保留时请先下载。

胜利且终审完成后进入侦探排行会保存本次结案，同一局重复打开只保留一条记录。按游戏消耗时间升序展示前 100 名，用时越短排名越靠前，同时间按入榜先后排序；榜外单独显示本次名次。名称可直接修改，调查报告按结案时的内容保存，可回看、导图。数据保存在 `src/data/leaderboard.json`，重启仍保留，不进入 Git；浏览器保存改名凭据与最近记录。排行榜由当前服务器上的玩家共用，成绩由客户端提交，尚无公网账号或服务端对局验真。

离线单文件保留已人工核对的预置 NASA／ESA 材料，明确标注离线演示，排行榜提示使用本地联网版。NASA 不同页面不代表独立机构，ESA 另一批照片的器材参数不能套给 NASA 原图。
